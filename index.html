Security & Transparency

Because this app is distributed outside the Google Play Store, Android's Play Protect may ask to scan it on first install. Every official release is scanned on VirusTotal and the full Kotlin source code is published on GitHub so anyone can inspect how it works.

No Root Required: Uses standard Android APIs (ActivityManager, TelecomManager, and SYSTEM_ALERT_WINDOW).
Honest OS Limits: On non-rooted phones, Android restricts reading kernel GPU stats on some devices and blocks silently deleting other apps' private caches.
